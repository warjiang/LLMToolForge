# 实用工具栏滚动与排序

## Goal

实用工具页面的工具入口在窄屏下仍可访问，并允许用户按使用习惯调整工具 Tab 顺序。

## Requirements

- 工具 Tab 栏保持单行展示，窗口变窄时通过横向滚动访问右侧工具，不裁掉入口。
- 支持通过拖拽调整工具顺序，高频工具可以移动到左侧或右侧。
- 用户自定义顺序需要本地持久化；刷新或重新进入页面后保持顺序。
- 新增工具或旧配置缺失工具时，使用默认顺序补齐，避免用户配置导致工具消失。
- 提供重置顺序入口，恢复到默认工具顺序。
- 当前选中工具在排序后保持选中；如果持久化值无效，则回退到默认第一个工具。

## Acceptance Criteria

- [ ] 缩窄实用工具页面时，Tab 栏仍为单行，可横向滚动看到全部工具。
- [ ] 拖拽任意工具 Tab 到新位置后，展示顺序立即变化。
- [ ] 刷新页面或重新打开应用后，自定义工具顺序仍然生效。
- [ ] 点击重置顺序后，Tab 顺序恢复为 `TOOL_TAB_ORDER` 默认顺序。
- [ ] 单测覆盖顺序归一化、持久化读取、拖拽排序和重置顺序。

## Notes

- 用户已选择方案 A：单行横向滚动 + 拖拽排序。
- 不新增一级导航，不引入新依赖；复用项目已有 `@dnd-kit`。
