# Manual Acceptance

- [ ] 远程模型：快速灵感能生成 2/3 个题目和三个不同方法的示例。
- [ ] 远程模型：训练模式能逐级提示、评价并在评价后解锁示例。
- [ ] 端侧模型：通过 Unified Gateway 完成同样的两个流程。
- [ ] 模型切换会被记住；删除当前模型后自动回退并提示。
- [ ] 网关停止后首次调用会按需启动。
- [ ] 网关启动失败时显示可恢复错误和统一网关入口。
- [ ] 评价失败后题目和答案不丢失，重试可以继续。
- [ ] 有未提交答案时换题需要确认。
- [ ] 最近记录最多 50 条，可查看、删除单条和清空。
- [ ] 历史写入失败不隐藏已生成结果。
- [ ] 中文界面请求中文结果，英文界面请求英文结果。
- [ ] 切换界面语言不会篡改已有历史内容。
