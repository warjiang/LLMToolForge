# Prompt 收藏库与快速套用

## Goal

在 Agent 输入框中提供一个本地 Prompt 收藏库，让用户可以收集、管理、搜索并
快速套用可复用的 Prompt 模板。首版采用显式的一次性模型：套用 Prompt 时把模板
文本插入输入框，保持可见、可编辑，发送时复用现有消息与 Agent 运行时链路，
不做任何隐藏注入。

本 PRD 是需求与验收口径的权威来源；技术边界与实现细节见 `design.md`。

## Requirements

### 数据与持久化
- 新增 `PromptTemplate`（`name/description/content/tags/sourceUrl?/favorite`），
  复用现有 `Repository<T>` + `createCollectionStore`。
- 复用现有加密数据同步（S3/对象存储），把 `promptTemplates` 注册为普通 sync
  资源；**同时**把 store 加入 `reloadSyncedData` 的 `syncedCollectionStores`
  （两处注册，缺第二处会导致“同步成功但界面不刷新”）。
- Prompt 记录进入不可变加密历史快照，可随快照恢复。

### 模板语法（§6，三规则模型）
- 唯一可选 token `{{input}}`，非必需。行为只由两个可感知事实决定：输入框是否
  为空、模板是否含 `{{input}}`——不依赖用户不可见的光标条件。空字符串或仅含
  空白字符的输入框都视为“空框”。
  - Rule 1 空框：插入；含占位符则选中第一个，否则光标到末尾。
  - Rule 2 非空 + 含 `{{input}}`：用已有全文替换所有 `{{input}}`，结果覆盖整个
    输入框（不看光标，但已有文本仍完整保留在占位符位置）。
  - Rule 3 非空 + 无占位符：光标处插入，保留前后文，替换选区。
- 展开只发生在“套用”时，从不在发送时运行；套用后是普通可编辑文本。

### 交互
- 工具栏加 📖 Prompts 按钮，**对所有模型可用**（含图文/视频/多模态），不按
  模型能力禁用。首版仅限制 Prompt **正文**为纯文本；套用后仍可正常加附件。
- Picker：搜索框自动聚焦；空查询显示收藏/最近分段（空段不渲染），非空查询
  collapse 成单一过滤列表；搜索匹配 name/description/tags（**不匹配正文**）；
  结果按收藏优先、名称升序确定性排序；键盘可用（上下/Enter/Esc），Esc 不改动
  输入框。
- 管理弹窗：左列表 + 右编辑器，create/edit/favorite/delete；删除需确认，保存
  失败保留编辑内容。
- 最近使用为**应用进程级内存 MRU**：最多 5 个 Prompt ID，重复选用移到最前，
  已删除 ID 自动过滤，收藏项不在最近分段重复显示；不持久化、不进同步、不改
  `updatedAt`。

### 初始状态
- v1 不提供内置或预置 Prompt，不引入 seed、seed-version 或特殊记录类型。
- 首次打开为空库，用户通过管理弹窗创建第一条 Prompt。

### 会话标题（可延后）
- 首条消息标题可用套用前的问题（`titleHint`），避免模板会话标题雷同；
  纯锦上添花，延后不影响功能（回退到现有 28 字截断）。

## Acceptance Criteria

- [ ] 用户可管理持久化的本地 Prompt 集合（增/删/改/收藏/标签/搜索）。
- [ ] 可通过搜索、收藏、应用进程级最近使用、标签找到 Prompt。
- [ ] 空框时模板成为全部内容；非空且模板含 `{{input}}` 时用原全文填充占位符并
  覆盖输入框；非空且无占位符时才在光标/选区处插入并保留前后文。
- [ ] `{{input}}` 可选：写问题→套用、套用→继续写 两种流均成立（§6 三规则）。
- [ ] Prompt 按钮对所有模型可用；套用文本 Prompt 后仍可加附件。
- [ ] 发送无隐藏 Prompt 状态，走全部现有运行时链路（direct/Pi/外部 Agent）。
- [ ] 源 Prompt 后续编辑/删除不影响已发送消息的 retry。
- [ ] Prompt 作为独立加密对象存储资源备份；跨端同 bucket/prefix/口令可同步。
- [ ] 每个成功写出的加密快照都包含 Prompt 资源；快照写入失败保持现有非致命
  语义；快照恢复后 picker 无需重启即刷新。
- [ ] Prompt 正文与来源 URL 不出现在明文 manifest。
- [ ] 应用进程级最近使用仅内存，不能覆盖远端 Prompt 内容。
- [ ] 不改动任何 Agent 定义、Skill 协议、沙箱模式或 AAP 协议行为。
- [ ] 单测覆盖 `applyPromptTemplate` 三规则与校验/归一化。
- [ ] 所有新增 Prompt 测试文件已加入 `vitest.config.ts` 白名单，并在
  `pnpm test` 输出中确认被实际收集执行。

## Notes

- 用户已确认的关键取舍：`{{input}}` 可选、去掉按模型禁用、最近使用降级为内存版、
  不提供预置 Prompt、`titleHint` onChange 即清、搜索不匹配正文、picker 搜索态
  折叠。
- 遵循“最小改动、纯函数优先、TDD”，不新增全局状态框架、不新增一级导航页。
- 后续延后项：最近使用跨重启持久化；全文搜索 + 匹配片段预览；消息气泡的
  结构化 Prompt chips。
